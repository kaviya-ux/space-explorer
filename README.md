# 🚀 Space Explorer

A single-page, educational tour of our solar system — built with **only HTML and CSS**, no JavaScript or frameworks.

## Features

- **Hero section** with a CSS-only starfield and an animated orbital diagram
- **Planet cards** for all 8 planets, each one drawn with pure CSS radial gradients (no image files)
- **Missions timeline** covering key moments in space history, from Sputnik to JWST
- **Gallery strip + footer**
- Fully **responsive** (mobile, tablet, desktop)
- Respects `prefers-reduced-motion` for users sensitive to animation

## Tech

- Semantic HTML5
- CSS Grid & Flexbox for layout
- CSS custom properties (variables) for a consistent design system
- Google Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Sora](https://fonts.google.com/specimen/Sora), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## Run it locally

Just open `index.html` in your browser — no build step, no dependencies.
